A smaller, restorable backup

Compose files and mapped config are archived together. Containers are stopped for a consistent copy, then restarted before upload. Images and unselected media mounts stay out.

Google Drive

Mirror each new archive off-site.

Connect or reconnect Google Drive

On a LAN IP, run rclone authorize "drive" on your own computer, complete Google sign-in, then paste the token JSON below. Your Google password is never entered here.

Using a custom rclone client? Set the matching client ID and secret below before saving the token.

Browser OAuth / custom client

For browser sign-in, register a Google Web OAuth client with Drive API enabled. Use an HTTPS hostname or localhost, and sign in to this app at that hostname first. Google does not accept a private LAN IP as a web redirect.

Retention

Clean up successful backups after this many days. Failed uploads stay available for retry. The newest successful backup is always kept.

days
i
Your backups may contain secrets

Compose files, .env files and application config can contain credentials. Archives are compressed, not encrypted. Use a private NAS share and Drive folder. Mirroring adds backup files; it never syncs or deletes unrelated files.

ONLY WHAT MATTERS

Image mappings

Tell the app where each image keeps its config and application state.

i

Unknown images need a mapping before backup. Paths are inside the container. Review broad folders such as /data to avoid backing up media. Tags are ignored when matching.
